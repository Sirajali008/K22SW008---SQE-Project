# Student Management: Full Package

Everything is in one package. Start the whole app with one command.

## Quick start
1. Install Node.js 24 or later from https://nodejs.org (check with `node --version`).
2. Open a terminal in the Student_Frontend folder and run:

       node server.js

3. Open http://localhost:5173 in your browser.

The launcher starts the Student API automatically. Press Ctrl+C to stop both.

## Folders
- Student_Frontend: the web interface and launcher. Run this.
- Student_API: the REST API with SQLite (started for you). Its README covers Postman tests and API routes.
